# Camera catalog sources

`camera_database.json` combines camera and lens metadata from Gyroflow lens
profiles and Lensfun. The Lensfun input is pinned to commit
`a5e2caeb6b646b7a0bb9ed76033b56f8c0499e86`; its database is licensed under
CC BY-SA 3.0. The applicable license is included in
`LENSFUN-DATABASE-LICENSE.txt`. Source database:
https://github.com/lensfun/lensfun/tree/a5e2caeb6b646b7a0bb9ed76033b56f8c0499e86/data/db

The catalog is a modified compilation of Lensfun data merged with Gyroflow
profile data. Preserve this notice when redistributing it. The canonical
catalog generator and source documentation live in
https://github.com/gyroflow/lens_profiles.
